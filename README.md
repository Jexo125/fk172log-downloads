# FK172Log — Téléchargements

Carnet de trafic radioamateur pour la Nouvelle-Calédonie (préfixes **FK** et **172**).

## Télécharger la dernière version

Rendez-vous sur la page **Releases** de ce dépôt et téléchargez le fichier
`FK172Log-Setup-<version>.exe` (un seul fichier : il contient l'application
et l'installe chez vous).

- Windows 10 / 11
- Fonctionne aussi sans connexion à Internet (seule la recherche d'indicatif
  dans l'annuaire public HamDB utilise le réseau)

## En cas de problème au premier lancement

L'application n'étant pas signée (le certificat de signature est payant),
Windows ou votre antivirus peut afficher un avertissement : c'est normal.
Voir le fichier `LISEZMOI.txt` joint à l'installation, ou exclusions
recommandées pour Avast.
